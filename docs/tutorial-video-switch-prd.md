## 执行概要

WaveMod 教程页（`/guide`）目前仅有图文教程，用户在跟学时无法通过视频直观理解操作步骤。本功能在现有教程页上新增「图文 ↔ 视频」切换能力——每个章节内置切换按钮，点击后将图片替换为对应视频，整体布局和章节导航结构保持不变。00 节（工具下载）在视频模式下同时展示视频播放器和工具直链。视频播放器提供进度记忆、键盘快捷键等增强体验。

## 问题陈述

**现状**：教程页 5 个章节仅展示静态图文（截图 + 文字说明），用户遇到复杂操作时缺乏动态演示参考。

**方案**：每个章节新增「观看视频版」按钮，一键切换至视频教程；视频与图文步骤一一对应，布局与图文模式一致。00 节工具直链在视频模式下也完整保留。

**影响**：降低用户学习门槛，提升教程完成率，减少因看不懂图文而放弃的用户。

## 成功指标

**主要 KPI**：
- **视频播放率**：至少 30% 的教程访问者点击「观看视频版」
- **完播率**：视频播放完成率 > 50%（通过播放进度数据统计）
- **教程页退出率降低**：视频功能上线后教程页退出率下降至少 10%

**验证方式**：上线 2 周后通过前端埋点统计切换点击量、视频播放进度、页面停留时长。

## 用户故事与验收标准

### Story 1：图文教程中切换到视频版

**作为** MOD 安装新手  
**我想要** 在当前章节一键切换到视频教程  
**以便** 通过动态演示理解操作步骤

**验收标准**：
- [ ] 每个章节顶部显示提示条「📺 本节有视频教程」
- [ ] 点击「观看视频版」按钮后，内容区从图文切换为视频播放器
- [ ] 切换动画流畅（使用 framer-motion 与现有风格一致）
- [ ] 视频播放器中显示「返回图文版」按钮，点击可切回
- [ ] 切换不改变章节导航（Tab bar 保持不动）

### Story 2：视频播放器核心体验

**作为** 教程观看者  
**我想要** 流畅地观看视频教程，并能在不同会话间记住播放位置  
**以便** 不用每次从头开始

**验收标准**：
- [ ] 视频使用标准 HTML5 `<video>` 播放器，支持播放/暂停/进度条/音量/全屏
- [ ] 播放进度自动保存到 localStorage（按章节分 key 存储）
- [ ] 再次打开同一节视频时，从上次位置继续播放
- [ ] 键盘快捷键：`Space` 暂停/播放，`←→` 快退/快进 5 秒，`F` 全屏
- [ ] 播放器样式与现有 neo-brutalism 风格统一

### Story 3：00 节视频模式中保留工具下载

**作为** 教程观看者  
**我想要** 在 00 节的视频模式下也能下载必需工具  
**以便** 边看视频演示边获取工具

**验收标准**：
- [ ] 00 节视频模式下，视频播放器下方显示完整的工具下载列表
- [ ] 工具下载功能与图文模式完全一致（链接、云盘链接均可用）
- [ ] 布局清晰：视频在上，工具列表在下

### Story 4：进度恢复支持视频

**作为** 教程观看者  
**我想要** 系统记住我的学习进度（包括是在看图文还是视频）  
**以便** 下次回到教程页时能无缝继续

**验收标准**：
- [ ] 现有 Resume 横幅机制扩展支持视频位置
- [ ] 保存的进度包含：章节 ID、模式（图文/视频）、视频播放位置
- [ ] 点击 Resume 后自动切换到对应章节和模式

### Story 5：视频加载速度优先

**作为** 教程观看者（可能网络条件一般）  
**我想要** 视频快速加载播放  
**以便** 不用长时间等待加载

**验收标准**：
- [ ] 视频需经过压缩优化，目标单个文件 ≤ 30MB（画质可适度降低）
- [ ] 使用懒加载策略：仅在用户点击「观看视频版」后才加载视频资源
- [ ] 视频标签使用 `preload="none"`，避免初始页面加载时占用带宽

## 功能需求

### 核心功能 1：章节内视频切换按钮

- **描述**：每个章节（00-04）顶部显示提示条「📺 本节有视频教程」+ 切换按钮
- **用户流程**：
  1. 用户浏览某章节图文教程
  2. 看到提示条，点击「观看视频版」
  3. 内容区带过渡动画切换为视频播放器
  4. 视频播放器顶部有「返回图文版」按钮
  5. 点击返回，切回图文内容
- **边界情况**：如果某章节无对应视频文件，不显示提示条和按钮（从 config 控制）
- **错误处理**：视频加载失败时显示友好提示「视频加载失败，请尝试图文教程」

### 核心功能 2：增强视频播放器

- **描述**：自定义样式的 HTML5 视频播放器，带进度记忆和键盘快捷键
- **进度记忆**：播放过程中每 5 秒将当前时间写入 localStorage，key 格式 `wavemod-video-{chapterId}`
- **键盘快捷键**：
  - `Space`：播放/暂停（阻止页面滚动）
  - `ArrowLeft`：快退 5 秒
  - `ArrowRight`：快进 5 秒
  - `F`：切换全屏
- **样式**：使用 neo-brutalism 风格——粗边框、硬阴影、与现有设计系统一致

### 核心功能 3：Config 扩展

- **描述**：在 `tutorialConfig` 的章节定义中新增 `video` 字段
- **数据结构**：
  ```ts
  video?: {
    src: string;       // 视频文件路径，如 "/video/01-1.mp4"
    poster?: string;   // 视频封面图（可选，默认视频第一帧）
  }
  ```
- **00 节特殊处理**：`type: "text"` 的章节在视频模式下同时展示视频和工具列表

### 核心功能 4：视频压缩与优化

- **描述**：将现有的 184MB → 目标压缩至 ≤ 30MB，使用 H.264 编码、720p 分辨率
- **加载策略**：仅在切换时加载 `<video>` 元素（条件渲染），`preload="none"`
- **工具**：使用 ffmpeg 压缩，脚本化批量处理

### 不在范围内

- 视频弹幕/评论功能
- 视频播放速度调节（如 1.5x / 2x）
- 视频自动播放
- 画中画模式

## 技术约束

### 性能
- 视频组件仅在切换时挂载（条件渲染），不影响图文模式页面加载速度
- 视频使用 `preload="none"`，不预加载
- 单视频压缩至 ≤ 30MB

### 兼容性
- 使用标准 HTML5 `<video>`，支持 MP4 (H.264) 编码
- 目标浏览器：Chrome 90+, Firefox 90+, Edge 90+, Safari 15+
- 移动端：全屏播放支持，触摸操作正常

### 技术栈
- 前端：Next.js 15, React 19, TypeScript, Tailwind CSS, Framer Motion
- 视频存储：`public/video/` 目录（本地静态文件）
- 状态管理：React useState + localStorage

## 风险评估

| 风险 | 概率 | 影响 | 缓解策略 |
|------|------|------|----------|
| 视频压缩后画质太差用户不满意 | 中 | 中 | 保留原始文件备份，压缩参数可调；提供 720p + 480p 两档 |
| 大视频加载慢影响体验 | 高 | 中 | 懒加载 + preload="none" + 压缩；未来可选 CDN |
| localStorage 空间不足 | 低 | 低 | 仅存储时间戳（字节级），做好 try/catch |
| 移动端视频体验差 | 中 | 低 | 使用原生 controls，全屏播放自动适配 |
