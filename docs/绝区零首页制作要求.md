# 绝区零分站首页制作要求记录

本文档记录绝区零分站首页后续开发必须遵守的要求。后续制作下半部分、继续调整上半部分或新增组件时，必须优先参照本文档。

## 1. 总目标

- 制作游戏切换里的「绝区零」分站首页。
- 参考图：`ui_images/首页.png`。
- 只使用参考图的布局结构，不使用参考图的视觉风格。
- 视觉风格必须继续使用本站现有 neo-brutalism 风格，参考 `docs/样式参考.md`。
- 当前任务阶段：先完成上半约 `50vh`，后续开始制作下半约 `50vh`。

## 2. 参考图使用规则

### 允许参考

- 页面区块的位置关系。
- 元素排列顺序。
- 导航栏布局结构。
- 首屏大图轮播布局。
- 下半部分的模块关系，例如：
  - 统计条。
  - Featured Mods 横向卡片。
  - 右侧 Latest Updates。
  - Popular Categories。
  - 上传/创作者 CTA。
  - 底部创作者/信任条。

### 禁止参考

- 禁止使用参考图的原始视觉风格。
- 禁止照搬参考图的颜色、暗黑科技风、细线框、圆角玻璃卡片等视觉语言。
- 禁止照搬参考图导航栏文案内容，例如 `Browse Mods`、`Character Mods`、`Weapon Mods`、`Community` 等。

## 3. 视觉风格要求

- 视觉风格必须来自 `docs/样式参考.md`。
- 必须保持当前站点 neo-brutalism 设计语言：
  - 厚黑边框。
  - 硬阴影。
  - 高饱和色块。
  - 贴纸式旋转。
  - 大字号黑体/粗体。
  - 快速机械式 hover/active 反馈。
- 不要引入新的设计体系。
- 新增卡片必须用现有站点风格重新创建，不能使用参考图原始卡片风格。
- 毛玻璃可以存在，但不能和现有风格违和。
- 毛玻璃效果应放在导航栏背景层，不应放在每个按钮自身上。

## 4. 导航栏要求

### 布局

- 导航栏布局参考 `ui_images/首页.png`：
  - 左侧 Logo/站点标识。
  - 中间导航链接。
  - 右侧搜索/功能入口。
- 导航栏不需要和下方 hero 文案严格对齐。
- 导航栏左右两侧不应该有过多空白。
- 导航栏整体应更接近参考图的横向铺开效果。

### 内容

- 导航栏内容必须使用鸣潮根目录导航栏的内容语义，而不是参考图导航内容。
- 绝区零导航栏应包含：
  - `WaveMod / 绝区零 MOD 分站`。
  - `游戏切换`。
  - `首页`。
  - `角色分类`。
  - `先看我`。
  - `支持本站`。
  - 搜索。
  - `收藏`。
  - `登录 / 退出`。
  - `直链下载`。
- `游戏切换`保留多游戏入口。
- `角色分类`跳转绝区零 MOD 列表。

### 数据路径

- 搜索框必须对应绝区零数据路径：
  - `/zenless-zone-zero/mods?query=xxx`
- 角色分类必须对应绝区零分站：
  - `/zenless-zone-zero/mods`
- 下载入口必须对应绝区零分站：
  - `/zenless-zone-zero/mods`
- 教程入口必须对应绝区零分站：
  - `/zenless-zone-zero/guide`

## 5. 首屏 Hero 要求

- 上半屏约 `50vh`。
- 结构为单张大图背景轮播。
- 内容叠加在图片上。
- 首屏必须能看到：
  - 导航栏。
  - 左侧标签。
  - 主标题。
  - `Explore. Customize. Download Fast.`。
  - 描述文案。
  - 两个按钮。
  - 轮播进度条。
  - 右侧信息卡。
- 不能因为标题过大导致副标题、说明、按钮或进度条消失。
- 进度条不要覆盖按钮。
- 如果空间不足，优先调整：
  - 标题字号。
  - `line-height`。
  - 上下 `margin`。
  - 内容区 `padding-bottom`。
  - 进度条定位。
- 进度条可以使用绝对定位固定到 hero 底部，但必须避开按钮。

## 6. 间距要求

- 图片上的内容不能离两侧太远。
- 导航栏内容不能因为容器过窄而两侧留白过多。
- 但导航栏不需要和 hero 文案对齐。
- 按钮和卡片内间距不能太小，必须保持可点击和可读。
- 后续调整优先考虑视觉平衡，不要一味压缩 padding。

## 7. 下半部分制作要求

后续开始制作下半约 `50vh` 时：

- 必须参考 `ui_images/首页.png` 的下半屏布局结构。
- 必须在首屏内尽量看到完整上下两部分内容。
- 下半部分应按参考图语义还原模块，但视觉必须使用本站 neo-brutalism 风格。
- 当前绝区零页面上旧的热门推荐、榜单、通用模块，该删的删。
- 新增模块若当前网站不存在，需要用现有风格创建一致卡片。
- 建议下半部分模块包含：
  - 统计条模块。
  - Featured Mods 横向卡片区域。
  - 右侧 Latest Updates 卡片。
  - 右侧 Popular Categories 卡片。
  - 上传/创作者 CTA。
  - 底部创作者/信任条。

## 8. 数据与语义要求

- 绝区零分站展示文案必须是绝区零语义。
- 不应在绝区零页面出现明显鸣潮角色文案，例如“今汐主题角色外观”。
- 如果绝区零真实数据尚不足，可以使用现有图片作为背景，但展示文案应适配绝区零。
- 后续接入真实绝区零数据后，组件应能自然替换。

## 9. Next.js 组件边界要求

后续所有组件必须遵守 `next-best-practices`：

- Server Components 优先。
- 不要整块页面都使用客户端渲染。
- 只有需要浏览器状态或交互的局部才使用 `'use client'`。
- 导航栏应尽量是 Server Component。
- 搜索如无复杂客户端联动，优先使用原生表单提交。
- Hero 外层数据整理应为 Server Component。
- 轮播状态、上一张/下一张、进度条点击等交互，拆成小型 Client Component。
- Client Component 只接收可序列化 props。
- 避免把不需要的服务端逻辑塞进客户端组件。
- 后续新增下半部分模块默认应为 Server Component。
- 只有折叠、轮播、复制、弹窗、收藏即时交互等必要部分才拆 Client Component。
