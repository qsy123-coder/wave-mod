# 香港服务器部署指南

本指南帮助你将 WaveMod 项目部署到香港服务器，实现中国用户快速访问。

## 前置准备

### 1. 购买香港服务器

推荐配置：

```text
阿里云香港轻量应用服务器
- 2核2G
- 峰值带宽 30M
- 系统：Ubuntu 22.04 LTS
- 月付约 24 元起
```

或腾讯云香港轻量服务器（配置类似）。

### 2. 购买域名

推荐在以下平台购买：

- 阿里云（万网）
- 腾讯云
- Cloudflare

域名后缀推荐：`.com` / `.net` / `.cn`

### 3. 注册 Cloudflare

访问 https://cloudflare.com 注册免费账号。

## 部署步骤

### 步骤 1：连接服务器

使用 SSH 连接到你的香港服务器：

```bash
ssh root@你的服务器IP
```

首次登录建议修改 root 密码：

```bash
passwd
```

### 步骤 2：安装 Node.js 22

```bash
# 添加 NodeSource 仓库
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -

# 安装 Node.js
apt install -y nodejs

# 验证安装
node -v
npm -v
```

### 步骤 3：安装 Git

```bash
apt install -y git
```

### 步骤 4：克隆项目代码

```bash
# 进入工作目录
cd /var/www

# 克隆代码（替换为你的仓库地址）
git clone https://github.com/你的用户名/WaveMod.git

# 进入项目目录
cd WaveMod
```

如果是私有仓库，需要配置 SSH 密钥或使用 HTTPS + Personal Access Token。

### 步骤 5：配置环境变量

创建生产环境变量文件：

```bash
nano .env.production
```

复制 `.env.production.template` 的内容并填写真实值：

```env
NEXT_PUBLIC_SITE_URL=https://你的域名.com

NEXT_PUBLIC_SUPABASE_URL=你的Supabase项目URL
NEXT_PUBLIC_SUPABASE_ANON_KEY=你的Supabase匿名密钥
SUPABASE_SERVICE_ROLE_KEY=你的Supabase服务角色密钥

ADMIN_EMAIL=你的管理员邮箱

ALIBABA_CLOUD_ACCESS_KEY_ID=你的阿里云AccessKeyId
ALIBABA_CLOUD_ACCESS_KEY_SECRET=你的阿里云AccessKeySecret

ALIYUN_DYPNS_SIGN_NAME=你的短信签名
ALIYUN_DYPNS_TEMPLATE_CODE=100001
ENABLE_SUPABASE_PHONE_OTP=true

ALIYUN_OSS_REGION=oss-cn-hangzhou
ALIYUN_OSS_BUCKET=你的OSS Bucket名称
ALIYUN_OSS_ENDPOINT=https://oss-cn-hangzhou.aliyuncs.com
ALIYUN_OSS_ACCESS_KEY_ID=你的OSS AccessKeyId
ALIYUN_OSS_ACCESS_KEY_SECRET=你的OSS AccessKeySecret
```

保存并退出（Ctrl+X，然后 Y，然后 Enter）。

### 步骤 6：安装依赖并构建

```bash
# 安装依赖
npm ci

# 构建生产版本
npm run build
```

构建过程可能需要几分钟。

### 步骤 7：安装 PM2

PM2 是 Node.js 进程管理器，用于保持应用持续运行。

```bash
npm install -g pm2
```

### 步骤 8：启动应用

```bash
# 使用 PM2 启动应用
pm2 start npm --name wavemod -- start

# 查看应用状态
pm2 status

# 查看日志
pm2 logs wavemod

# 保存 PM2 配置
pm2 save

# 设置开机自启
pm2 startup
```

执行 `pm2 startup` 后会输出一条命令，复制并执行它。

### 步骤 9：安装 Nginx

```bash
apt install -y nginx
```

### 步骤 10：配置 Nginx 反向代理

创建 Nginx 配置文件：

```bash
nano /etc/nginx/sites-available/wavemod
```

粘贴以下内容（替换 `你的域名.com`）：

```nginx
server {
    listen 80;
    server_name 你的域名.com www.你的域名.com;

    client_max_body_size 50m;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";

        proxy_read_timeout 300s;
        proxy_connect_timeout 75s;
    }
}
```

启用配置：

```bash
# 创建软链接
ln -s /etc/nginx/sites-available/wavemod /etc/nginx/sites-enabled/

# 测试配置
nginx -t

# 重启 Nginx
systemctl restart nginx
```

### 步骤 11：配置 HTTPS

安装 Certbot：

```bash
apt install -y certbot python3-certbot-nginx
```

申请 SSL 证书：

```bash
certbot --nginx -d 你的域名.com -d www.你的域名.com
```

按提示输入邮箱并同意服务条款。

Certbot 会自动修改 Nginx 配置并重启服务。

证书会自动续期，无需手动操作。

### 步骤 12：配置防火墙

```bash
# 安装 UFW
apt install -y ufw

# 允许 SSH
ufw allow 22

# 允许 HTTP
ufw allow 80

# 允许 HTTPS
ufw allow 443

# 启用防火墙
ufw enable

# 查看状态
ufw status
```

## Cloudflare 配置

### 步骤 1：添加站点到 Cloudflare

1. 登录 Cloudflare
2. 点击 "添加站点"
3. 输入你的域名
4. 选择免费套餐
5. 点击继续

### 步骤 2：修改域名 NS 记录

Cloudflare 会显示两个 NS 记录，例如：

```text
ns1.cloudflare.com
ns2.cloudflare.com
```

前往你的域名注册商（阿里云/腾讯云等）：

1. 找到域名管理
2. 修改 DNS 服务器/NS 记录
3. 替换为 Cloudflare 提供的 NS 记录
4. 保存

等待 DNS 生效（几分钟到几小时）。

### 步骤 3：配置 DNS 记录

在 Cloudflare DNS 管理页面添加记录：

```text
类型    名称    内容                代理状态
A       @       你的服务器IP        仅DNS（灰云）
CNAME   www     你的域名.com        仅DNS（灰云）
```

**重要：不要开启橙云代理**，保持灰云（DNS only）状态。

### 步骤 4：配置 SSL/TLS

在 Cloudflare SSL/TLS 设置中：

- 加密模式：选择 "完全（严格）"

这样 Cloudflare 会验证你服务器的 Let's Encrypt 证书。

## Supabase 配置

### 更新 Site URL

在 Supabase 项目设置中：

1. 进入 Authentication → URL Configuration
2. 设置 Site URL：`https://你的域名.com`
3. 添加 Redirect URLs：
   - `https://你的域名.com/auth/callback`
   - `https://www.你的域名.com/auth/callback`

保存后等待几分钟生效。

## 故障排查

### 应用无法启动

```bash
# 查看详细日志
pm2 logs wavemod --lines 100

# 检查环境变量
cat .env.production

# 检查端口占用
netstat -tlnp | grep 3000
```

### 502 Bad Gateway

可能原因：

1. Next.js 应用未启动
2. Nginx 配置错误
3. 端口不匹配

解决方法：

```bash
# 检查应用状态
pm2 status

# 检查 Nginx 配置
nginx -t

# 查看 Nginx 错误日志
tail -f /var/log/nginx/error.log
```

### 域名无法访问

可能原因：

1. DNS 未生效
2. 防火墙未开放端口
3. Nginx 未启动

解决方法：

```bash
# 检查 DNS
nslookup 你的域名.com

# 检查防火墙
ufw status

# 检查 Nginx
systemctl status nginx
```

### 登录回调失败

检查：

1. Supabase Site URL 是否正确
2. Redirect URLs 是否包含你的域名
3. `.env.production` 中的 `NEXT_PUBLIC_SITE_URL` 是否正确

## 性能优化建议

### 1. 启用 Gzip 压缩

编辑 Nginx 配置：

```bash
nano /etc/nginx/nginx.conf
```

确保以下配置已启用：

```nginx
gzip on;
gzip_vary on;
gzip_proxied any;
gzip_comp_level 6;
gzip_types text/plain text/css text/xml text/javascript application/json application/javascript application/xml+rss application/rss+xml font/truetype font/opentype application/vnd.ms-fontobject image/svg+xml;
```

### 2. 配置缓存

在 Nginx server 块中添加：

```nginx
location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
}
```

### 3. 监控资源使用

```bash
# 查看内存使用
free -h

# 查看磁盘使用
df -h

# 查看 CPU 使用
top
```

## 安全建议

### 1. 禁用 root SSH 登录

创建普通用户：

```bash
adduser deploy
usermod -aG sudo deploy
```

配置 SSH：

```bash
nano /etc/ssh/sshd_config
```

修改：

```text
PermitRootLogin no
PasswordAuthentication no
```

重启 SSH：

```bash
systemctl restart sshd
```

### 2. 定期更新系统

```bash
apt update && apt upgrade -y
```

### 3. 配置自动备份

建议定期备份：

- 项目代码
- 环境变量文件
- Nginx 配置
- SSL 证书
