产品需求文档 (PRD)：鸣潮角色MOD个人网站
文档版本：V1.0 (2026年4月)
产品定位：专注《鸣潮》（Wuthering Waves）角色MOD的高质量、单主理人发布平台。

1. 项目概述与核心价值
   1.1 项目背景
   针对《鸣潮》玩家群体对高质量角色MOD的需求，建立一个专注且纯粹的个人作品展示与分发网站。
   1.2 核心价值与差异化竞品分析
   • 极致下载体验：彻底摒弃传统网盘的提取码、限速等痛点，提供基于阿里云OSS的高速直链下载。
   • 本地化友好：全中文界面，专为中国大陆玩家优化的网络访问链路（Cloudflare + CNAME优化）。
   • 纯净易用：界面无冗余广告，提供清晰的高清大图/视频预览，以及一键复制的XXMI Launcher安装指引。
   • 单人维护模式：站长（您）作为唯一的MOD提供者，保证内容质量的绝对把控。

---

2. 目标用户与系统角色
   • 目标用户 (C端)：以中国大陆地区为主的《鸣潮》PC端玩家、MOD爱好者。
   • 系统角色：
   o 普通访客：可浏览MOD列表、查看详情、直接下载MOD文件、查看安装教程。
   o 注册用户：除访客权限外，可进行评论互动、收藏MOD（管理个人收藏夹）。
   o 管理员 (仅限站长)：登录专属后台，进行图文/视频/ZIP文件的上传、编辑、版本管理及用户互动管理。

---

3. 核心功能需求
   3.1 C端：用户前台功能
   • 全局导航模块。首页和内容页
   o 顶部固定（Sticky）：Logo、全局搜索框、先看我（教程）、角色分类锚点。
   o 用户入口：、登录/注册、我的收藏、支持本站（变现入口）。
   • 首页发现模块
   o Hero横幅区：轮播图展示最新或最热门（结合点赞、收藏数、评论、点击更新）的顶级MOD作品，视觉冲击力强。
   o 角色Tabs分类：点击角色名称，无刷新过滤展示对应的MOD，筛选有按角色筛选及你认为适合的筛选方法等，排序有按mod点赞，收藏排序等以及网格布局，列表布局。
   o MOD瀑布流/网格区：展示MOD封面图、标题、展示、点赞/收藏数、点击量、mod演示跳转按钮。（响应式布局：桌面端3-4列，移动端2列）。
   • MOD详情页模块
   o 左侧视觉区：支持图片/短视频的轮播预览，提供大尺寸、清晰的视觉展示。
   o 右侧信息与操作区 (粘性吸顶)：
    MOD标题、详细描述、当前版本号、适用游戏版本标签。
    下载核心区：高亮大尺寸直链下载按钮。
    使用指引：一键复制XXMI Launcher安装说明及路径。
   o 互动区：下方提供用户评论列表（支持实时刷新）、点赞与收藏（❤️）按钮。
   3.2 B端：管理员后台功能
   • 路径：/admin/upload（鉴权保护，仅特定账号可访问）。
   • 发布管理：
   o 提供表单上传入口，支持一次性上传预览图、演示视频和MOD ZIP压缩包。
   o 对接阿里云OSS接口，上传后自动将直链写入Supabase数据库。
   o 表单字段：标题、角色归属、版本标签、描述正文、NSFW警告开关、mod作者链接、演示视频链接（点击后跳转到演示页面，可以放视频展示）。
   3.3 商业化支持功能（变现模块）
   • 赞助接口：在全局导航及每个详情页底部，集成 Patreon / 爱发电 / 微信赞赏 的跳转链接或打赏码。
   • 功能预留：底层数据库结构需为后续可能增加的“会员专属MOD（VIP可见）”预留权限字段。

4. 界面与交互规范 (UI/UX)
   • 主题风格：多个主题切换：1.仅仅参考该文件“样式参考.md”的样式风格，布局不完全采纳。2.使用文件“样式参考.md”的风格，只把颜色风格改为深色沉浸式游戏风（黑紫渐变配色），契合《鸣潮》及二次元极客审美。
   • UI组件库：基于 shadcn/ui 定制，保证组件的专业感与一致性。
   • 响应式适配：全站需兼容PC端（宽屏图片展示）及移动端（流式布局、触控轮播）。
   • 性能感知：图片采用懒加载（Lazy Loading），点击下载时提供清晰的加载反馈（Loading Spinner）。

1. 技术架构与部署方案
   模块 技术栈/服务商 核心职责与优势
   前端框架 Next.js 16 (App Router) + TypeScript 优秀的SEO支持，服务端渲染提升首屏加载速度，代码结构清晰。
   样式方案 Tailwind CSS + shadcn/ui 快速构建现代深色风格UI，高度可定制，体积小。
   后端/数据库 Supabase (Free Tier) PostgreSQL存元数据；Auth处理登录；Realtime处理评论；小体积预览图存储。
   大文件存储 阿里云OSS (或腾讯云COS) 核心：存储MOD的ZIP大文件，生成国内高速直链，彻底解决下载慢的痛点。
   托管部署 Vercel (Hobby 计划) 前端页面零成本托管，CI/CD自动化部署。
   网络加速 Cloudflare (Proxy) + 自定义域名 优化CNAME解析（如 cname-china.vercel-dns.com），解决纯Vercel国内常被墙或加载慢的问题。
   注：当前采用方案一简化版部署，即“Vercel前端 + CF加速 + 阿里云直链”。该方案小而精，极度适合项目启动。

1. 成本预估与控制模型 (2026最新参考)
   本产品以低成本验证期为起点，具备高扩展性。
   • 固定免费部分：Vercel (带宽100GB内)、Cloudflare、Supabase 免费层。
   • 主要成本源：阿里云 OSS
   o 存储费用：约 0.09元/GB/月（建议购买包年：100GB/年约99元，500GB/年约119元）。
   o 流量费用：公网流出闲时0.25元/GB，忙时0.5元/GB。
   成本阶段推演：
1. 极早期 (下载量 < 100GB/月)：0–20元/月。
1. 起步成长期 (下载量 200–500GB/月)：20–150元/月。
1. 流量爆发期 (下载量 1TB+/月)：200–500元/月（此时应转入方案二混合部署，并购买大额度流量包降低单价）。
   降本策略：强制压缩所有MOD文件体积；在网站上温和提示用户“尽量在夜间/清晨（闲时）下载”。

1. 风险提示与注意事项
1. 版权与合规风险：MOD涉及游戏官方资产。必须在全站Footer和下载页显著位置标明：“本站内容仅供学习与交流用途，与游戏官方无关”。
1. 内容分级：如涉及清凉/NSFW向MOD，必须在上传表单强制要求勾选标签，并在前端增加“18+”或“NSFW”视觉警告，避免违规被举报。
1. 兼容性维护：游戏每次大版本更新后，可能导致旧MOD失效。需建立“失效反馈”机制或在后台快捷标记MOD的“当前可用性”状态。
1. 防盗链配置：阿里云OSS需配置防盗链（Referer白名单），仅允许您的域名直接调用下载，防止被其他网站恶意嵌套消耗您的流量费用。
